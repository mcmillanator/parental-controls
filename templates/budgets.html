Implementation

Flask + Jinja + vanilla JavaScript + Bootstrap 5, no React/framework and no build step: every budget row, window and override is server-rendered from the live data, and every save POSTs form-encoded data to the existing Flask endpoints (progressive enhancement keeps it async).

Bootstrap 5 is vendored locally under static/vendor/bootstrap/; product tokens, theme, focus and table-to-card rules live in static/css/app.css (the mockup's static/css/tokens.css). static/js/app.js is progressive enhancement only.

The Bootstrap grid lays category rows out as labelled cards below the mobile breakpoint; the row order, labels and actions are preserved. Accessibility: labelled inputs, aria-live on the refresh status, text + icon (never colour alone), 44px targets, reduced motion honoured. No CDN or external assets.
